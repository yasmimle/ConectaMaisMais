# Conecta++

O Conecta++ é um sistema web desenvolvido para apoiar ONGs no gerenciamento de informações de idosos, oferecendo uma plataforma organizada para cadastro, acompanhamento e administração dos atendimentos.

## Sobre o projeto

Este projeto foi desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas com o objetivo de aplicar conceitos de desenvolvimento web, banco de dados e programação orientada a objetos. A aplicação possui diferentes níveis de acesso (administrador e atendente), gerenciamento de usuários, controle de interesses, conteúdos informativos e recursos de acessibilidade para proporcionar uma melhor experiência aos usuários.

## Funcionalidades

* Cadastro de usuários (idosos);
* Login de administradores e atendentes;
* Gerenciamento de administradores;
* Gerenciamento de atendentes;
* Cadastro e gerenciamento de interesses e necessidades;
* Consulta e atualização de registros;
* Conteúdos informativos sobre saúde e prevenção de golpes;
* Recursos de acessibilidade com VLibras.

## Tecnologias utilizadas

### Back-end

* C#
* ASP.NET Core MVC (.NET 8)
* Entity Framework Core
* SQL Server
* Autenticação por Cookies

### Front-end

* HTML5
* CSS3
* JavaScript
* Bootstrap

### Banco de Dados

* SQL Server
* Script SQL para criação do banco de dados

```text
ConectaPlusPlus

```

## Como executar o projeto

1. Clone este repositório.
2. Execute o script localizado na pasta **BancoDeDados** para criar o banco.
3. Configure a conexão no arquivo `appsettings.json`.
4. Abra o projeto no Visual Studio.
5. Execute a aplicação.
